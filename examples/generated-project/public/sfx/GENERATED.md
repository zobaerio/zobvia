# SFX files in this sample

When this project was generated by `scripts/create_video.py`, this folder
held 7 generated WAV files (whoosh, thud, pluck, chime, pop, click, swipe —
see `src/data/sfx.json` for the event map). They are not committed to git
because they are binary; regenerate them any time with:

```bash
python3 scripts/sfx_gen.py --out <this-project>/public/sfx
```

(from the zobvia skill root), or simply re-run the converter.

# Style: Dark Tech (example)

> Filled example produced by the LEARN pipeline (A0–A8). Numbers are the
> style's measured signature — reproduce the numbers, never the source
> creator's footage, voice, music, or exact graphics.

## 1. Pacing
- Average shot length: 1.8 s (33 shots/min)
- Hook section (0–10 s): 1.2 s average; body: 2.1 s; ending: 1.5 s
- Punch-in 110% on every 3rd cut; 115% on emphasis cuts

## 2. Framing
- Talking head: close, centre-frame, eye-line at 38% height
- B-roll: screen recordings wide, then punch-in on the cursor target
- Safe margins: subject never inside outer 8%

## 3. Transitions
- 85% hard cuts, 10% zoom-blur cuts (6f), 5% whip pans (6–8f, only on `!` moments)
- No fades except chapter dip-to-black (10f)

## 4. Captions
- 2 words per caption, word-by-word, offset 4 frames
- Active word: cyan `#38BDF8`, scale 1.08, soft bounce; inactive: white `#F8FAFC`
- Font: bold sans, 700 weight, size ≈ 5.5% of frame height
- Position: bottom third, baseline at 78% height; no stroke, soft shadow

## 5. Overlays
- Tool names as small monospace chips, top-left, fade-up 6f
- Cursor ring highlight on clicks; progress bar 4px top, cyan

## 6. Color
- Background `#0A1929` (Deep Navy), panels `#1F2937`, accent `#38BDF8`, text `#F8FAFC`, muted `#94A3B8`
- One accent only; contrast ≥ 4.5:1 verified for caption text

## 7. Audio
- Voice pace ≈ 2.6 words/sec; silences > 0.4 s cut
- SFX: whoosh 0.35 vol on every hard cut; soft pop on chip reveals; no music in CREATE recreations (SFX-only policy) — original used 90 BPM lo-fi at −18 dB under voice (note only, never reuse the track)

## 8. Hook (0–3 s)
- Big kinetic line on dark background, very soft thud on the main word
- First cut at 1.4 s; pattern interrupt = snap zoom 100% → 118%

## 9. Ending (last 5 s)
- Statement Card: one line + channel name chip; abrupt cut to black, no fade-out

## 10. Recipe
Hook (Kinetic) → tool montage (Dark Tech panels) → one big tool (Glossy UI) →
Timeline → Problem vs Solution → Data Dashboard → Statement Card → Recap Grid → CTA

## 11. Do-not
- No second accent colour; no serif fonts; no per-letter caption animation
- Never copy the source video's clips, voice, music, or thumbnail art

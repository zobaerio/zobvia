# Client Brief Template

Copy, paste and fill. Every field marked * is required before work starts.

```
CLIENT BRIEF — VIDEO PROJECT
============================
Client / channel name*:
Contact person + best contact*:
Date:

1. GOAL*
   What should this video achieve? (views / sales / signups / awareness / other):
   The ONE action a viewer should take after watching:

2. AUDIENCE*
   Who watches this? (age, country, language, interests):

3. PLATFORM & FORMAT*
   Platform(s): (YouTube long-form / Shorts / Reels / TikTok / Facebook / LinkedIn)
   Aspect ratio: (16:9 / 9:16 / 1:1 / 4:5)
   Target duration*:
   Number of videos in this job:

4. CONTENT
   Topic / working title*:
   Key points that MUST be covered (in order):
   Anything that must NOT be said or shown:
   Call to action (exact wording / link / handle):

5. LANGUAGE & VOICE*
   Caption language(s): (BN / EN / BN+EN / AR / UR / HI / other)
   Voiceover: (client provides / record for me / TTS agreed / none — SFX + captions only)
   Script: (client provides final script / draft needed — approval step included)

6. BRAND
   Brand colours (hex if known)*:        ← the ONE colour question: confirm these are final
   Logo file provided? (Y/N, format):
   Fonts (if brand-specific):
   Tone: (energetic / calm / premium / funny / formal / other)

7. ASSETS PROVIDED
   [ ] Footage   [ ] Photos   [ ] Logo   [ ] Script   [ ] Voiceover   [ ] Music (licence proof attached)
   File link(s):

8. REFERENCES
   Videos whose style you like (links + what you like about each):
   A learned style skill to apply (name, if any):

9. DELIVERY*
   Deadline (date + timezone):
   Deliverables: (video / + SRT / + thumbnail / + ZIP archive)
   Revision rounds included: (default 2 — see agreement)

10. RIGHTS & APPROVALS
    I confirm I have the rights to use all assets I supplied: (Y/N)
    Music/SFX must be licence-safe for commercial use: (Y/N)
    Final approver name:
```

## Notes for the Editor (not sent to client)

- Missing colour, platform or duration = stop and ask; everything else can be drafted around.
- A client-supplied song without licence proof goes through `music-sfx-sourcing.md` red-flag handling.
- Log every later change request in the project `notes.md` with date + who asked — scope creep is settled from that log.

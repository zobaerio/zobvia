# Prompt Library — Ready-to-Say Prompts

Copy a prompt, swap the [brackets]. Grouped by mode. 32 prompts.

> **Flagship:** the full Master CREATE Prompt lives in
> `references/master-create-prompt.md` — one paste (prompt + your SRT)
> runs the entire CREATE pipeline with exactly one colour question.

## LEARN Mode — Extract a Style

1. "Learn the style from this video: [link/file]. Save it as a style skill named [name]."
2. "Watch this video and tell me its caption style, pacing, colours and SFX — then save that as a reusable style."
3. "Learn this creator's style from these 3 videos and merge it into one style skill: [links]."
4. "Update my [name] style skill — re-learn from this newer video and save it as a new version, don't overwrite the old one."
5. "Compare the style of video A [link] and video B [link] — what exactly does A do differently?"
6. "What styles have you learned for me? List the style skills and when each was made."

# Genre Recipes — 20 Recipes

Each recipe is a starting configuration. A learned style skill (LEARN mode) overrides any recipe. Format: Pipeline / Pacing / Captions / Palette tone / Hook / CTA.

### 1. Tech Review
Pipeline: product-hero + spec cards. Pacing: medium-fast, cut on spec changes. Captions: Boxed Bold. Palette: dark + one electric accent. Hook: #9 Tool Reveal or #13 Comparison. CTA: #5 Product Link + #3 Comment Question.

### 2. Education Explainer
Pipeline: whiteboard/diagram build + keyword pop. Pacing: steady, pause after each concept. Captions: Karaoke Highlight. Palette: light, high-contrast text. Hook: #2 Open Question. CTA: #11 Save Prompt + #6 Playlist Binge.

### 3. Islamic / Waz
Pipeline: speaker-led, ayat/hadith quote cards, no faces-animation gimmicks. Pacing: slow, respectful pauses. Captions: RTL Arabic for quotes + Bilingual Stack BN+EN for speech. Palette: deep green/gold or calm neutral. Hook: #8 Story Cold-Open or a quote card — never shock hooks. CTA: #10 Bengali Creator CTA (share for sadaqah framing only if creator's own words). Music: none / SFX minimal — no instruments policy by default; ask, never assume.

### 4. News Package
Pipeline: VO-led B-roll + lower-thirds. Pacing: brisk, information-dense. Captions: News Lower-Third. Palette: channel news colours, restrained. Hook: #7 Headline News Style. CTA: #1 Subscribe Reminder.

### 5. Vlog
Pipeline: handheld-feel, jump cuts, location cards. Pacing: fast, cut silences. Captions: Boxed Bold. Palette: natural, warm. Hook: #8 Story Cold-Open mid-action. CTA: #9 Loop-Back or #3 Comment Question.

### 6. Product Ad (15–30 s)
Pipeline: hero → problem → demo → proof → offer. Pacing: fast, beat-led. Captions: Word Pop (offer line only). Palette: brand colours, high contrast. Hook: #10 Result First. CTA: #5 Product Link with real price/offer from brief only.

### 7. Real Estate Tour
Pipeline: room-by-room crane/pan moves, spec overlays (size, price from brief). Pacing: smooth medium. Captions: Minimal Line. Palette: bright, airy, warm. Hook: #10 Result First (best room first). CTA: #4 Lead Magnet / contact from brief.

### 8. Restaurant Promo
Pipeline: close-up food shots, steam/sizzle SFX forward. Pacing: fast cuts on action (pour, flip, serve). Captions: Word Pop Yellow (dish names). Palette: warm, saturated. Hook: #10 Result First (hero dish). CTA: #5 Product Link / location + #11 Save Prompt.

### 9. Online Course Lesson
Pipeline: slide/diagram + instructor inset, chapter cards. Pacing: slow-medium, recap beats. Captions: Karaoke Highlight. Palette: clean light or brand dark. Hook: #5 Number Promise (lesson outcomes). CTA: #6 Playlist Binge (next lesson).

### 10. Motivational
Pipeline: big centre text, slow zooms, cinematic stills. Pacing: builds — slow start, strong finish. Captions: Hormozi Stack or Word Pop Yellow. Palette: dark + gold/white. Hook: #1 Bold Claim. CTA: #11 Save/Share Prompt.

### 11. Documentary Short
Pipeline: interview + B-roll, natural sound breaks. Pacing: slow, let moments breathe. Captions: Soft Subtitle Film. Palette: muted, filmic. Hook: #8 Story Cold-Open. CTA: #8 Soft Brand Outro.

### 12. Podcast Clip (vertical)
Pipeline: speaker cam(s), waveform/quote pop, guest name card. Pacing: cut to the single best exchange. Captions: Word Pop or Karaoke. Palette: studio brand. Hook: the clip's strongest line as frame 1 (#15 Direct Address style). CTA: "Full episode" — #6 Playlist style, link in caption/description.

### 13. Gaming
Pipeline: gameplay-first, facecam inset, kill/replay zooms. Pacing: very fast, beat-synced. Captions: Neon Glow. Palette: saturated, game-matched. Hook: #6 Pattern Interrupt Zoom on the play. CTA: #1 Subscribe + #3 Comment Question.

### 14. Fitness
Pipeline: demo angles, rep counters, form-cue text pops. Pacing: energetic, timed to reps. Captions: Boxed Bold / Hormozi Stack. Palette: bold, high energy. Hook: #4 Before/After Tease (only with real, consented results). CTA: #11 Save Prompt (workout for later).

### 15. Fashion
Pipeline: outfit reveals, spin/slide transitions, detail close-ups. Pacing: beat-led medium-fast. Captions: Minimal Line (let visuals lead). Palette: editorial, seasonal. Hook: #10 Result First (final look). CTA: #5 Product Link.

### 16. Corporate Profile
Pipeline: lock-off interviews, office B-roll, stat cards, logo outro. Pacing: measured. Captions: Minimal Line / News Lower-Third for names. Palette: brand, desaturated, trustworthy. Hook: a real company stat (#18 Proof Flash). CTA: #8 Soft Brand Outro + contact from brief.

### 17. Wedding Highlight
Pipeline: Ken Burns + slow dissolves, vows audio under B-roll. Pacing: slow, emotional. Captions: Soft Subtitle Film (sparse — vows/key lines only). Palette: warm, soft, filmic. Hook: the vow/kiss moment, 1 s tease. CTA: none / #8 Soft Brand Outro (vendor credit only if agreed).

### 18. Travel
Pipeline: drone-style rises, location cards, map moment. Pacing: medium, wonder beats held 2–3 s. Captions: Minimal Line + location lower-thirds. Palette: vivid but natural. Hook: #10 Result First (the view). CTA: #11 Save Prompt (itinerary).

### 19. Kids Content
Pipeline: bright characters, bounce animations, sound-led jokes. Pacing: fast but clear; repeat key words. Captions: Emoji Accent (early readers: large, slow). Palette: primary, high saturation. Hook: #12-style curiosity in simple words / character question. CTA: #10-style simple subscribe via parent-facing end line. Safety: no scary stingers, no strobe, volume gentle.

### 20. Finance Explainer
Pipeline: chart builds, number counters, example walk-through. Pacing: steady; pause on every number. Captions: Karaoke Highlight + stat cards. Palette: dark/blue trust tones + green/red only for data. Hook: #16 Loss Warning or #18 Proof Flash. CTA: #4 Lead Magnet (calculator/checklist). Always: "not financial advice" note where the creator's format requires it; never invent figures.

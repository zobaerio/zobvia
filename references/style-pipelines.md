# Style Pipelines — the 16

A pipeline is a complete visual system: layout, surfaces, type
treatment, and motion habits. CREATE picks pipelines in step B4.
Each entry: **look / layout / best for**.

## Layout families (never mix families in one video)

- **Grid family:** Bento Grid, Data Dashboard, Checklist/Recap Grid
- **Stage family:** Glossy UI Mockup, 3D Carousel, Glass Cards,
  Minimal Clean, Kinetic Typography, Gradient Fluid, Statement Card
- **Flow family:** Timeline/Process Flow, Hub-and-Spoke
- **Free family** (pairs with stage only): Dark Tech, Before/After
  Split, Flat Vector/Isometric, Line-Draw/Doodle

## The 16

1. **Glossy UI Mockup** — *Look:* realistic app/browser frames, soft
   shadows, reflections. *Layout:* one large device/browser frame
   centre-stage, callouts around it. *Best for:* software, apps,
   tutorials, product features.
2. **3D Carousel** — *Look:* cards on a rotating 3D arc, depth blur.
   *Layout:* centre card hero, neighbours angled away. *Best for:*
   lists of 4–8 items, features, options, pros/cons sets.
3. **Dark Tech** — *Look:* near-black background, neon accent, mono
   details, grid lines. *Layout:* stage with terminal/code/UI panels.
   *Best for:* programming, AI, engineering, cybersecurity.
4. **Glass Cards** — *Look:* frosted translucent cards over a gradient
   or blurred colour field. *Layout:* 1–3 floating cards, generous
   space. *Best for:* modern explainers, finance, SaaS concepts.
5. **Bento Grid** — *Look:* rounded tiles of mixed sizes, each tile one
   fact. *Layout:* strict grid, tiles populate in stagger. *Best for:*
   summaries, feature overviews, multi-stat scenes.
6. **Minimal Clean** — *Look:* white/off-white, one accent, lots of
   empty space, thin type. *Layout:* single element per scene, centred
   or left-aligned. *Best for:* serious topics, education, health,
   anything where trust beats flash.
7. **Kinetic Typography** — *Look:* type *is* the visual — huge words,
   rotation, scale play. *Layout:* full-frame text compositions, no
   cards. *Best for:* hooks, quotes, manifestos, short punchy SRTs.
8. **Data Dashboard** — *Look:* charts, KPI numbers, small multiples.
   *Layout:* dashboard grid, counters and bars animate. *Best for:*
   statistics, reports, comparisons with real numbers in the SRT.
9. **Timeline / Process Flow** — *Look:* a path or spine with nodes
   lighting up in sequence. *Layout:* horizontal or vertical flow,
   one node per cue. *Best for:* steps, history, how-things-work,
   journeys.
10. **Hub-and-Spoke** — *Look:* one central concept, satellites connect
    by lines. *Layout:* centre node + 3–6 spokes, drawn on in order.
    *Best for:* definitions, ecosystems, cause maps, categories.
11. **Before/After Split** — *Look:* two halves, divider wipes between
    states. *Layout:* split screen, labels pinned to each half.
    *Best for:* transformations, mistakes vs fixes, old vs new.
12. **Checklist / Recap Grid** — *Look:* tick rows or recap tiles with
    satisfying completion states. *Layout:* list/grid that fills as
    points are covered. *Best for:* recaps, summaries, action plans,
    final-third scenes of longer videos.
13. **Flat Vector / Isometric** — *Look:* flat shapes, isometric scenes,
    simple character/object illustrations built from primitives.
    *Layout:* scene compositions, elements slide/pop into place.
    *Best for:* physical processes, construction, geography, kids'
    education.
14. **Gradient Fluid** — *Look:* slow-moving gradient blobs/mesh behind
    bold text. *Layout:* full-bleed colour field, text centre-stage.
    *Best for:* emotional topics, introductions, transitions between
    heavy sections, channel branding moments.
15. **Line-Draw / Doodle** — *Look:* hand-drawn stroke aesthetic,
    draw-on animation, paper or chalkboard ground. *Layout:* sketches
    build up element by element. *Best for:* teaching, derivations,
    brainstorming feel, whiteboard-style lessons.
16. **Statement Card** — *Look:* one sentence, huge, on a solid colour
    ground; nothing else. *Layout:* full-frame card, text centred.
    *Best for:* the single most important line, chapter breaks,
    conclusions. Use sparingly — max 2–3 per video.

## Choosing guide

| SRT signal | First choice | Pair with |
|---|---|---|
| App/software steps | Glossy UI Mockup | Statement Card |
| Number-heavy, stats | Data Dashboard | Minimal Clean |
| Steps / sequence words ("first… then…") | Timeline/Process Flow | Checklist/Recap Grid |
| One concept, many parts | Hub-and-Spoke | Glass Cards |
| List of items/features | 3D Carousel | Bento Grid |
| Tech / code topic | Dark Tech | Glossy UI Mockup |
| Teaching, school topic | Line-Draw/Doodle | Minimal Clean |
| Physical / real-world process | Flat Vector/Isometric | Timeline/Process Flow |
| Comparison in the text | Before/After Split | Data Dashboard |
| Short, emotional, quote-like | Kinetic Typography | Gradient Fluid |
| Serious / trust topic | Minimal Clean | Glass Cards |
| End-of-video recap cues | Checklist/Recap Grid | Statement Card |

Decision order: (1) a learned style's recipe wins; (2) the table
above; (3) default to Minimal Clean + Statement Card. Stay inside one
layout family; the "pair with" column already respects families
(stage+free and within-family pairs only).

## The 60–90 s recipe arc

For a typical 60–90 s SRT (~25–40 cues), structure the whole video as:

1. **Hook (0–3 s, 1–2 cues):** Kinetic Typography or Statement Card —
   biggest text of the video, first SFX within 1 s.
2. **Setup (next ~15%):** the primary pipeline establishes the world
   (layout, card style, motion habits the viewer will learn).
3. **Body (~60%):** primary pipeline carries the points; the paired
   pipeline appears for lists, numbers, or contrasts — max 2–3 style
   switches per minute, always on a section change, always with a
   transition + SFX.
4. **Payoff (~15%):** the SRT's strongest line gets a Statement Card or
   the primary pipeline at hero scale; chime SFX allowed here.
5. **Recap/close (final ~10%):** Checklist/Recap Grid restating the
   points in compressed form, or a Statement Card echoing the hook.
   Last frame holds ≥ 1 s.

Shorter videos (< 30 s): hook + body + one statement card. Longer
videos (> 90 s): repeat the body/payoff cycle per section, with a
Statement Card as the chapter break between sections.

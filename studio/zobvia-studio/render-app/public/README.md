# public/ — runtime assets

Everything in this folder is served by Remotion and referenced from code
with `staticFile("...")` — never with a bundled `import`, so a missing file
cannot break the build.

| Path | What goes here |
|---|---|
| `voiceover.mp3` | The final voiceover for the whole video. After placing it, set `HAS_VOICEOVER = true` in `src/timing.ts` and render the `PreviewAudio` composition (or copy its `<Audio>` line into `Main`). Until then the flag stays `false` and nothing references the file. |
| `sfx/` | Sound effects ONLY (zobvia rule: SFX, no music). Generated by the skill's `scripts/sfx_gen.py` or dropped in by hand, e.g. `sfx/whoosh.wav`, `sfx/pop.wav`. Reference as `staticFile("sfx/whoosh.wav")`. |
| `assets/` | Images, logos, screenshots and other stills used by scenes, e.g. `assets/logo.png`. Reference as `staticFile("assets/logo.png")`. Keep the official logo file byte-identical — never re-encode it. |

The `.gitkeep` files exist only so these empty folders survive in git /
in a ZIP of the template. Delete them once real files are in place.
